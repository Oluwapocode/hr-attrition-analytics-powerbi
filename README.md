# HR Attrition Analytics & Workforce Retention Dashboard
HR Analytics Dashboard built using SQL, power BI, and Excel.

### Overview

This project analyzes employee attrition patterns within an organization to identify factors driving workforce turnover and provide retention-focused recommendations.

### Tools Used

- SQL (MySQL)
- Power BI
- Microsoft Excel

### Key Questions

- What is the overall attrition rate?
- Which departments lose the most employees?
- Does overtime increase attrition?
- Are lower-paid employees more likely to leave?
- Does work-life balance affect retention?

### Key Findings

- Total Employees: 1,470
- Attrition Rate: 16.1%
- Research & Development recorded the highest number of employee departures (133).
- Employees working overtime were significantly more likely to leave.
- Sales Representatives had the highest attrition rate (39.76%).
- Lower-paying job roles generally experienced higher attrition, for example the Average Monthly Income  for Sales Representative was       $2,626
- Poor work-life balance was associated with lower retention.

### Recommendations

- Reduce excessive overtime.
- Improve work-life balance initiatives.
- Review compensation for high-risk roles.
- Develop targeted retention strategies for vulnerable departments and job roles.
